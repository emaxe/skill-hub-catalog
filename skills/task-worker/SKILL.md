# Task Worker

Ты -- агент-воркер. Выполни ровно одну задачу из файлового таск-трекера.

## Шаг 1: Найди каталог задач

Используй glob с паттерном `**/.agents/tasks/catalog.md` -- `**` обязателен, каталог
может находиться в любом подпроекте (пример: `src/ui/Operator.UI/.agents/tasks/`).
Если каталогов несколько -- выбери тот, в котором есть доступные задачи.
Если ни одного не найдено -- сообщи "Каталог задач не найден" и остановись.

## Шаг 2: Найди доступную задачу

Прочитай catalog.md. В таблице задач найди первую (наименьший номер) задачу,
которая удовлетворяет обоим условиям:

- Статус = строго `pending`. Статусы `in-progress`, `done`, `review`, `failed` не подходят.
- Зависимости выполнены: колонка "Зависимости" = `--` (нет зависимостей),
  либо все перечисленные задачи имеют статус `done`

Если такой задачи нет -- сообщи "Нет доступных задач" и перечисли
заблокированные с причинами. Остановись.

## Шаг 3: Возьми задачу

Обнови catalog.md: поставь статус `in-progress` для выбранной задачи.

## Шаг 4: Выполни задачу

1. Прочитай файл задачи (ссылка в колонке "Файл")
2. Прочитай AGENTS.md проекта и следуй конвенциям
3. Выполни задачу строго по инструкциям в файле
4. Проверь все пункты из секции "Критерии готовности"
5. Проверь ошибки (lint, TS)

## Шаг 5: Заверши

Обнови catalog.md: поставь статус `done` для выполненной задачи.
Сообщи какую задачу выполнил и остановись.

## При ошибке

Поставь `failed` в catalog.md, сообщи причину, остановись.

## Правила

- Выполняй ровно одну задачу. Не бери следующую после завершения.
- Не создавай и не меняй файлы задач. Только выполняй работу и обновляй статусы.
- Если в задаче указаны конкретные пути файлов -- используй их.
- Никогда не берёт задачу со статусом `in-progress` -- она уже занята другим агентом.
- Источник истины о статусе задачи -- только `catalog.md`. Файлы, открытые в редакторе, имеют наименьший приоритет.
